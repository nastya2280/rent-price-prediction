# rent-price-prediction
Прогнозирование стоимости аренды квартир в Москве
Проект по регрессии: предсказание месячной арендной платы квартиры в Москве на основе её характеристик. Сравнение линейных и ансамблевых моделей машинного обучения.
## Задача

Платформа по аренде недвижимости хочет автоматизировать ценообразование: быстро определять справедливую цену для новых объявлений и минимизировать время простоя. Нужно построить модель, которая по характеристикам квартиры предсказывает `monthly_rent_rub`.
**Тип задачи:** регрессия.

## Данные

- **Источник:** [Moscow Real Estate Sales and Rentals 2020–2026 (Kaggle)](https://www.kaggle.com/datasets/sergionefedov/moscow-real-estate-sales-and-rentals-20202026)
- **Размер:** ~20 000 записей, 22 признака
- **Целевая переменная:** `monthly_rent_rub` — месячная арендная плата в рублях

**Признаки:**
- География: `district`, `okrug`, `lat`, `lon`, `to_center_km`, `metro_station`, `metro_line`, `metro_distance_min`
- Характеристики квартиры: `total_area`, `rooms`, `floor`, `total_floors`, `building_year`
- - Тип дома и ремонта: `building_type`, `renovation`
- Условия аренды: `furnished`, `pets_allowed`, `deposit_months`

## Что было сделано

### 1. Предобработка
- Пропусков и дубликатов не обнаружено.
- Целевая переменная логарифмирована (`np.log1p`) — распределение сильно скошено вправо.
- One-Hot Encoding для низкокардинальных признаков (`okrug`, `renovation`, `metro_line`, `building_type`).
- Target Encoding для высококардинальных (`district`, `metro_station`) — с расчётом среднего только на обучающей выборке для избежания утечки.
- Feature Engineering: `area_per_room`, `is_center`, `floor_ratio`, `building_age`, `month`, `weekday`, `is_weekend`.
- Масштабирование через `StandardScaler`.
- ### 2. EDA
- Распределение цен сильно скошено: большинство квартир в бюджетном и среднем сегменте, длинный правый хвост.
- Чем больше комнат — тем выше аренда (boxplot).
- Наиболее дорогие округа: ЗАО, ЮЗАО; самые дешёвые: Троицкий и Зеленоградский АО.
- Обратная зависимость цены от расстояния до центра и до метро.
- Корреляции с таргетом: `total_area` (0.41), `rooms` (0.36), `to_center_km` (−0.53), `metro_distance_min` (−0.51).

### 3. Моделирование
Протестированы 7 моделей: Linear Regression, Ridge, Lasso, Decision Tree, Random Forest, Gradient Boosting, XGBoost.

### 4. Интерпретация
- **Feature importance:** ключевые факторы — `district_mean`, `metro_station_mean`, `to_center_km`, `total_area`, `rooms`.

### 6. Проверка статистических гипотез
- **Гипотеза 1** (квартиры в центре дороже): подтверждена, p-value < 0.05.
- **Гипотеза 2** (тип ремонта влияет на цену): подтверждена, p-value < 0.05.
- **Гипотеза 3** (разрешение питомцев не влияет на цену): отвергнута, p-value < 0.05.

## Результаты

- **Лучшая модель:** Gradient Boosting, R² = 0.9385 на тестовой выборке.
- **Главный вывод:** сильнее всего на арендную плату влияют локация (район, близость к метро и центру) и физические характеристики квартиры (площадь, количество комнат).
- Средняя абсолютная ошибка модели — около 5 200 руб., что для рынка аренды Москвы является приемлемым показателем.
